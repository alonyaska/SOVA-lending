# Architecture

**Стек технологий (Текущий - Лендинг):**
- Vanilla HTML / CSS / JS (отказ от тяжелых фреймворков для скорости).
- Шрифты: IBM Plex Sans (текст), JetBrains Mono (код и терминал).

**Дизайн-система:**
- Строгий темный UI (фон `#0d0e10`, поверхности `#131418`, акцент `#4a9eff`).
- Глобальные CSS-переменные для всех токенов.
- **Терминальный футуристичный стиль:** 
  - Стилизация окон под консоль (заголовки `sys@core:~/path`, 3 системные точки).
  - Анимированные scanlines, имитация старых CRT-экранов.
  - Печатающиеся заголовки с мигающим курсором `|`.

**Стек мессенджера (планируемый по Roadmap):**
- Кроссплатформенные клиенты (Win, macOS, Linux, iOS, Android).
- E2E-шифрование: Signal Protocol.
- ML-часть: интеграция Whisper (локальное распознавание), LLM для саммаризации и ассистента.
