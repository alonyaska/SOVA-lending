# Project Brief: SOVA Messenger

**Что пилим?**
Sova — защищённый мессенджер нового поколения со встроенным AI. 

**Ключевые ценности (Core Values):**
1. **Бескомпромиссная безопасность:** E2E-шифрование по умолчанию (протокол Signal). Ключи хранятся только локально.
2. **AI-First подход:** Нейросети интегрированы на уровне ядра (встроенный ассистент, автосаммари, транскрипция войсов через Whisper, семантическая сортировка чатов).
3. **Для разработчиков:** Строгий код, терминальный футуристичный дизайн, Open API и вебхуки для создания скриптов и ботов.

**Текущий статус:**
Разработка стильного, терминально-футуристичного лендинга для презентации продукта и загрузки клиентов.
